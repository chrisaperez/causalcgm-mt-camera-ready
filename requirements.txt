# CausalCGM-MT runtime and test dependencies.
#
# TWO PINNING STYLES, DELIBERATELY
# --------------------------------
#   >=floor,<ceiling   The scientific core. The floor is the oldest release the
#                      code is written against; the CEILING is the next major,
#                      because that is where these projects make their breaking
#                      changes (NumPy 2.0 changed scalar promotion and removed
#                      `np.float_`; pandas 3.0 changes copy-on-write). Without a
#                      ceiling, `pip install -r requirements.txt` a year from now
#                      resolves to releases this code has never been run against,
#                      and the failure surfaces as a metric that moved rather
#                      than as an install error.
#
#   ==exact            Packages whose OUTPUT this repository depends on, not just
#                      their API: the ONNX toolchain (the exported graph and its
#                      opset are compared against the C++ runner by
#                      `scripts/verify_cpp_parity.py`), the LightGBM baseline arm
#                      that is a row in Table 1, the verified Parkes grid
#                      backend, and the dashboard's rendering stack.
#
# `requirements-lock.txt` records the exact set the suite was last verified
# against. Install that instead when you need to reproduce an environment rather
# than build a compatible one.
